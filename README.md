### Stellar Burgers - конструктор заказов
Приложение для сборки бургера, оформления заказа и просмотра ленты заказов в реальном времени.
**Репозиторий:** https://github.com/ioreshkin/burger-project

Ключевые элементы:
- Конструктор бургера с Drag & Drop
- глобальное состояние на Redux Toolkit
- React Router со страницами авторизации и профиля
- WebSocket для ленты заказов
- тесты: unit/component (Vitest) и e2e (Cypress)
